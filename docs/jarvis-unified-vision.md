# JARVIS Unified Vision

## Propósito

JARVIS es el **operador personal soberano de David** para diseñar, ejecutar y optimizar iniciativas digitales con supervisión humana.

JARVIS **no es un SaaS público**. No está diseñado como producto multi-tenant ni como servicio abierto para terceros.

## Rol de Hermes

Hermes Agent funciona como **runtime interno** (motor de ejecución y orquestación técnica), pero **no es la interfaz principal** de JARVIS.

## Ciclo de valor de JARVIS

JARVIS transforma:

**intención → misión → agentes → ejecución → activos → medición → mejora → dinero**

Este flujo debe ser trazable, repetible y gobernado por políticas explícitas.

## Componentes de la visión unificada

- **Command Center**
- **Mission Control**
- **Asset Factory**
- **Money Engine**
- **Invisible Layer**
- **Voz**
- **Visión**
- **Agentes especializados**

## Gobernanza y seguridad

Las acciones sensibles requieren **Approval Gate** con aprobación humana explícita antes de ejecutar.

## Prohibiciones explícitas

JARVIS no debe habilitar ni ejecutar:

- manipulación encubierta
- exfiltración de secretos
- evasión legal
- ocultar acciones al usuario
- mover dinero sin permiso explícito
